# Gerber 转 PCB

这是一个嘉立创 EDA / EasyEDA 专业版扩展，用于把 RS-274X Gerber 和 Excellon 钻孔文件重建为当前 PCB 中可编辑的图元。

> [!WARNING]
> 本项目处于实验阶段，目前使用 **KiCad 10.0.5 四层板**和 **KiCad 10.0.6 OpenRX-Gemini 六层板**两个 Gerber/Excellon 数据集，在 **嘉立创 EDA 专业版 3.2.175** 中进行验证。其他 KiCad 版本、其他 EDA/CAM、二层板及更多层板尚未经过系统测试。

OpenRX-Gemini 的 制造文件再导出包已用于逐层光栅差分和钻孔坐标比较。v0.6.1 已在空白 PCB 中完成重新导入与再次导出验证：全部 13 个制造图层在 10 µm 容差外均无缺失或多余区域，钻孔逐坐标、逐孔径一致。

Gerber 只包含最终制造图形，不包含原理图、器件/封装归属、焊盘编号、真实网络名或原始设计规则。本扩展生成的是便于检查和应急修改的无网络 PCB 图元，不是对原设计工程的无损恢复。

## 已验证范围

- KiCad 10.0.5 四层板与 KiCad 10.0.6 六层板，正片 RS-274X Gerber。
- 顶层、最多四个内层、底层、板框、顶/底阻焊、顶/底锡膏及顶/底丝印。
- KiCad `RoundRect`、嘉立创 EDA 紧凑型 `RoundRect`、C/R/O/P 标准孔径。
- 四层样板含 79 个圆形 via 与 24 个圆形通孔焊盘；六层样板含 240 个 via 与 20 个通孔焊盘；无槽孔、盲埋孔。
- 六层样板的 v0.6.1 再导出结果中，六个铜层、顶/底阻焊、顶/底锡膏、顶/底丝印和板框在 10 µm 光栅比较下均无超差区域；260 个主 PTH 孔及其中 240 个 Via 辅助孔逐坐标、逐孔径一致。

项目仓库不包含用于验证的商业/用户 PCB、KiCad 工程或 Gerber 样板；自动化测试使用代码内的最小化合成数据。

## 安装与使用

1. 在嘉立创 EDA 专业版 V3 打开一个 PCB 文档。
2. 进入“高级 → 扩展管理器 → 导入”，选择 `gerber-to-pcb_v0.6.1.eext`。若已安装同 UUID 的旧测试版，请先卸载旧版并完全退出、重启嘉立创 EDA，再导入新包。
3. 新建空白 PCB；扩展只追加图元，不会自动清除当前 PCB 中已有的导入结果。在 PCB 顶部菜单选择“Gerber 转 PCB → 导入 Gerber / 钻孔文件...”。
4. 选择多个制造文件，或直接选择一个 Gerber ZIP 包。
5. 检查预览中的文件、目标层与图元数量，确认后写入当前 PCB。
6. 导入后执行 DRC，并将生成结果与原 Gerber 叠图核对。

## 当前支持

- RS-274X 单位与坐标格式；绝对/增量坐标。
- 圆形、矩形、长圆形和正多边形孔径（C/R/O/P）。
- KiCad `RoundRect` 圆角矩形孔径宏。
- KiCad `RotRect` 旋转矩形孔径宏，以及由单一 outline primitive 构成的 `FreePoly` 多边形孔径宏；`FreePoly` 会按铜、阻焊、锡膏各层的绝对坐标分别重建为实体填充，不作为原生焊盘。
- 嘉立创 EDA 紧凑型 `RoundRect` 圆角矩形孔径宏。
- 嘉立创 EDA 再导出文件中的旋转 `Rect` 孔径宏。
- 直线、顺/逆时针圆弧、闪光和区域。
- Excellon 公制/英制圆孔。
- ZIP 包与多文件选择。
- 支持 `.g1`～`.g30`、`.gp1`～`.gp30` 内层文件；根据 X2 物理层号与文件名自动计算所需铜层数，当前 PCB 不足时在写入前只向上扩展叠层。
- 常见 KiCad、Altium/Protel 和 X2 FileFunction 图层命名自动映射，包括 `Copper,L1,Top`、内层与底层。
- 读取 KiCad X2 `ViaPad`、`SMDPad`、`ComponentPad` 和 Excellon `ViaDrill`、`ComponentDrill` 属性；根据 Excellon FileFunction 区分 PTH 与 NPTH，NPTH 写入为非金属化孔。
- 写入前统计与确认；写入失败时尝试删除本次已创建的图元。
- 填充接口使用最小参数调用；当前 EDA 版本仍拒绝有效图形时，先创建同层显式闭合折线并调用官方“转换为填充”接口，成功后删除临时折线。超过 900 点且无法在 5 µm 内安全简化的区域会经过面积校验后无损拆成多个相邻实体填充。
- 只有直接填充和折线转换都失败时，才使用 Gerber 绝对坐标扫描线兜底；扫描边界近似误差不超过约 20 µm。
- 顶/底铜层的 SMD flash 创建为无网络实体图形，阻焊和锡膏 flash 始终按 Gerber 绝对坐标分别写入，从而保留百分比缩减、偏移和一焊盘多开窗，并避免 EDA 自动派生额外开窗。
- 只有实际钻孔重建为原生通孔焊盘或过孔；能由通孔焊盘扩展值精确派生的阻焊 flash 不重复写入。
- 与实际钻孔重合的 `ViaPad` / `ComponentPad` 内层铜 flash 不再创建独立填充，由过孔或多层焊盘自动派生；真正的内层 Gerber 区域仍照常写入。via-in-pad 中同坐标的 `SMDPad` 仍会保留。
- 原生通孔圆角焊盘按 EDA 运行时实际要求传入圆角百分比，保持 Gerber 中的物理圆角半径。
- 非铜层 Gerber 圆弧按不超过 10° 的弦段写入，避免 EDA 创建圆弧后制造导出遗漏。
- 连续板框线段合并为单个显式闭合 Polyline；由于公开 API 没有原生 BoardOutline 创建接口，导入后仍需确认 EDA 是否识别板框。
- 优先根据 Excellon X2 `ViaDrill` / `ComponentDrill` 区分过孔与通孔焊盘；无 X2 属性时才回退到阻焊开窗启发式。过孔本体显式关闭自动阻焊开窗，Gerber 中存在的开窗仍作为独立图形写入。
- Gerber 与 Excellon 的坐标匹配允许 5 µm 制造格式量化误差。
- 兼容嘉立创 EDA 导出的“先开始 G36 区域、后选择孔径”顺序。
- 导入成功后主动显示本次涉及的全部铜层，并恢复非激活层正常亮度，便于立即核对多层结果。

## 重要限制

Gerber 是制造图形，不是 PCB 设计数据库，因此无法可靠恢复原理图、器件型号、封装归属、焊盘编号、真实网络名、设计规则或可重新铺铜的参数化覆铜。当前版本把无钻孔的顶/底层 flash 重建为无网络实体图形，把钻孔重建为无网络通孔焊盘或过孔。

以下内容目前仅给出警告或采用近似处理：

- 除 `RoundRect`、`RotRect` 和单一 outline `FreePoly` 之外的复合或含清除图元自定义孔径宏（AM）。
- 负片/清除极性（LPC）与复杂布尔叠加。
- 步进重复（SR）。
- Excellon 槽孔、盲埋孔，以及缺少 X2 / FileFunction 属性时可靠的钻孔分类。
- Gerber 字符串语义；丝印文字会以制造图形而不是可编辑文字存在。
- 单象限圆弧歧义和少数厂商私有方言。

## 已知差异

### SMD 图形不是原生焊盘

v0.6.0 的验证结果曾显示：原生 SMD 焊盘继承嘉立创 EDA 默认规则时，阻焊开窗相对原 KiCad 样板每边增加约 **0.0508 mm（2 mil）**。

v0.6.1 将 SMD flash 重建为实体图形，铜、阻焊和锡膏分别按 Gerber 几何写入。代价是这些 SMD 图形没有焊盘编号、网络或封装归属，不能像原生焊盘一样编辑；这也符合 Gerber 本身不含这些设计语义的事实。v0.6.1 已完成一次六层样板再次导出验证，但实际生产前仍必须针对自己的文件检查全部制造层。

### 制造文件中的钻孔拆分

嘉立创 EDA 一键导出可能同时生成包含全部 PTH 的钻孔文件和仅包含 via 的辅助钻孔文件。在其他 CAM 软件中手动载入时，应确认没有把相同 via 重复计算。

该扩展适合旧板复刻、机械参考和应急修改。导入后必须执行 DRC，并将所有制造层与原 Gerber 叠图核对；未经核对的输出不应直接用于下单生产。

## 自动发布

仓库包含 `.github/workflows/release.yml`。推送符合 `v*.*.*` 的版本标签时，GitHub Actions 会自动：

1. 校验标签版本与 `package.json`、`extension.json` 一致。
2. 执行测试、TypeScript 检查和 lint。
3. 构建 `.eext` 安装包。
4. 创建同名 GitHub Release，并上传 `.eext` 和 SHA-256 校验文件。

例如，确认 `package.json` 与 `extension.json` 的版本均为 `0.6.1` 后：

```shell
git tag v0.6.1
git push origin v0.6.1
```

普通分支 push 不会创建 Release；源码仓库本身也不会提交 `.eext` 二进制文件。

扩展基于嘉立创 EDA 专业版官方 `pro-api-sdk`，采用 Apache-2.0 许可。
