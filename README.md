# Gerber 转 PCB

这是一个嘉立创 EDA / EasyEDA 专业版扩展，用于把 RS-274X Gerber 和 Excellon 钻孔文件重建为当前 PCB 中可编辑的图元。

> [!WARNING]
> 本项目处于实验阶段，目前只使用 **KiCad 10.0.5 导出的一个四层板 Gerber/Excellon 数据集**，在 **嘉立创 EDA 专业版 3.2.175** 中完成导入与再次导出验证。其他 KiCad 10.0 小版本、其他 EDA/CAM、二层板、六层及更多层板尚未经过系统测试。

Gerber 只包含最终制造图形，不包含原理图、器件/封装归属、焊盘编号、真实网络名或原始设计规则。本扩展生成的是便于检查和应急修改的无网络 PCB 图元，不是对原设计工程的无损恢复。

## 已验证范围

- KiCad 10.0.5、四层板、正片 RS-274X Gerber。
- 顶层、两个内层、底层、板框、顶/底阻焊、顶层锡膏及顶层丝印。
- KiCad `RoundRect`、嘉立创 EDA 紧凑型 `RoundRect`、C/R/O/P 标准孔径。
- 79 个圆形 via 钻孔、24 个圆形通孔焊盘钻孔；无槽孔、盲埋孔。
- 嘉立创 EDA 再导出结果中，铜层、板框、钻孔、锡膏和丝印几何已与原文件叠图核对。

项目仓库不包含用于验证的商业/用户 PCB、KiCad 工程或 Gerber 样板；自动化测试使用代码内的最小化合成数据。

## 安装与使用

1. 在嘉立创 EDA 专业版 V3 打开一个 PCB 文档。
2. 进入“高级 → 扩展管理器 → 导入”，选择 `gerber-to-pcb_v0.6.0.eext`。
3. 在 PCB 顶部菜单选择“Gerber 转 PCB → 导入 Gerber / 钻孔文件...”。
4. 选择多个制造文件，或直接选择一个 Gerber ZIP 包。
5. 检查预览中的文件、目标层与图元数量，确认后写入当前 PCB。
6. 导入后执行 DRC，并将生成结果与原 Gerber 叠图核对。

## 当前支持

- RS-274X 单位与坐标格式；绝对/增量坐标。
- 圆形、矩形、长圆形和正多边形孔径（C/R/O/P）。
- KiCad `RoundRect` 圆角矩形孔径宏。
- 嘉立创 EDA 紧凑型 `RoundRect` 圆角矩形孔径宏。
- 直线、顺/逆时针圆弧、闪光和区域。
- Excellon 公制/英制圆孔。
- ZIP 包与多文件选择。
- 常见 KiCad、Altium/Protel 和 X2 FileFunction 图层命名自动映射，包括 `Copper,L1,Top`、内层与底层。
- 根据 KiCad Excellon FileFunction 区分 PTH 与 NPTH；NPTH 写入为非金属化孔。
- 写入前统计与确认；写入失败时尝试删除本次已创建的图元。
- 填充接口使用最小参数调用；当前 EDA 版本仍拒绝有效图形时，先创建同层显式闭合折线并调用官方“转换为填充”接口，成功后删除临时折线，因此每个 Gerber 区域仍对应一个填充图元。
- 只有直接填充和折线转换都失败时，才使用 Gerber 绝对坐标扫描线兜底；扫描边界近似误差不超过约 20 µm。
- 顶/底铜层 flash 创建为原生焊盘，同坐标的阻焊与锡膏 flash 不重复生成，由焊盘自动派生。
- 与实际钻孔重合的内层铜 flash 不再创建独立填充，由过孔或多层焊盘自动派生；真正的内层 Gerber 区域仍照常写入。
- 圆角焊盘按 EDA 运行时实际要求传入圆角百分比，保持 Gerber 中的物理圆角半径。
- 非铜层 Gerber 圆弧按不超过 10° 的弦段写入，避免 EDA 创建圆弧后制造导出遗漏。
- 连续板框线段合并为单个显式闭合 Polyline；由于公开 API 没有原生 BoardOutline 创建接口，导入后仍需确认 EDA 是否识别板框。
- 根据钻孔坐标处是否存在阻焊 flash 区分通孔焊盘与盖油过孔；盖油过孔显式设置负阻焊扩展。
- Gerber 与 Excellon 的坐标匹配允许 5 µm 制造格式量化误差。
- 兼容嘉立创 EDA 导出的“先开始 G36 区域、后选择孔径”顺序。

## 重要限制

Gerber 是制造图形，不是 PCB 设计数据库，因此无法可靠恢复原理图、器件型号、封装归属、焊盘编号、真实网络名、设计规则或可重新铺铜的参数化覆铜。首版把顶/底层闪光重建为无网络焊盘，把钻孔重建为无网络通孔过孔。

以下内容目前仅给出警告或采用近似处理：

- KiCad `RoundRect` 之外的自定义孔径宏（AM）。
- 负片/清除极性（LPC）与复杂布尔叠加。
- 步进重复（SR）。
- Excellon 槽孔、盲埋孔和可靠的 PTH/NPTH 分类。
- Gerber 字符串语义；丝印文字会以制造图形而不是可编辑文字存在。
- 单象限圆弧歧义和少数厂商私有方言。

## 已知差异

### 原生焊盘派生的阻焊开窗

为了避免同一位置重复叠加图元，顶/底铜层 flash 会重建为嘉立创 EDA 原生焊盘，同坐标的阻焊与锡膏 flash 不再单独写入，而由原生焊盘自动派生。

在当前验证环境中，嘉立创 EDA 再导出的阻焊开窗相对原 KiCad 样板每边增加约 **0.0508 mm（2 mil）**，即总宽和总高增加约 0.1016 mm；锡膏开口保持一致。这符合当前 EDA 默认阻焊规则的表现，本扩展 **不会强制覆盖为零扩展**。实际结果取决于当前 PCB 的设计规则，导入后必须检查阻焊层。

盖油 via 会显式使用负阻焊扩展，已验证的 79 个 via 没有被自动开窗。

### 制造文件中的钻孔拆分

嘉立创 EDA 一键导出可能同时生成包含全部 PTH 的钻孔文件和仅包含 via 的辅助钻孔文件。在其他 CAM 软件中手动载入时，应确认没有把相同 via 重复计算。

该扩展适合旧板复刻、机械参考和应急修改。导入后必须执行 DRC，并将所有制造层与原 Gerber 叠图核对；未经核对的输出不应直接用于下单生产。

## 自动发布

仓库包含 `.github/workflows/release.yml`。推送符合 `v*.*.*` 的版本标签时，GitHub Actions 会自动：

1. 校验标签版本与 `package.json`、`extension.json` 一致。
2. 执行测试、TypeScript 检查和 lint。
3. 构建 `.eext` 安装包。
4. 创建同名 GitHub Release，并上传 `.eext` 和 SHA-256 校验文件。

例如，确认 `package.json` 与 `extension.json` 的版本均为 `0.6.0` 后：

```shell
git tag v0.6.0
git push origin v0.6.0
```

普通分支 push 不会创建 Release；源码仓库本身也不会提交 `.eext` 二进制文件。

扩展基于嘉立创 EDA 专业版官方 `pro-api-sdk`，采用 Apache-2.0 许可。
